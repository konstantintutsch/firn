# Agent instructions

- Commit automatically when a change is finished, without being asked.
- Write commit messages according to [Conventional Commits](https://www.conventionalcommits.org).
- **Branching**: Always create a new branch per topic, named `<type>/<topic>`.
- **Main Branch**: Agents should never commit directly to the `main` branch.
- **Granularity**: Commits should be granular and not too large. Each commit should focus on one component, not multiple (e.g., not front- and backend).
